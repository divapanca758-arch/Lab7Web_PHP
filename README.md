# PRAKTIKUM 7 - PEMROGRAMAN SERVER-SIDE PHP

## 1. Tujuan Praktikum
- Memahami dasar pemrograman PHP.
- Memahami variabel dan tipe data.
- Menggunakan operator dan percabangan.
- Menggunakan perulangan dan array.
- Membuat function.
- Memproses form menggunakan GET dan POST.
- Membuat aplikasi formulir data mahasiswa.

## 2. Perangkat yang Digunakan
- Laptop atau komputer
- XAMPP
- Visual Studio Code
- Google Chrome atau browser lainnya

## 3. Langkah Menjalankan Program
1. Buka aplikasi XAMPP.
2. Jalankan Apache.
3. Buka Visual Studio Code.
4. Buka folder lab7_php.
5. Simpan seluruh file PHP di dalam folder.
6. Buka browser.
7. Masukkan alamat localhost sesuai nama file.

## 4. Daftar Latihan
- Latihan 1: Menjalankan PHP.
- Latihan 2: Variabel, operator, dan percabangan.
- Latihan 3: Perulangan dan array.
- Latihan 4: Membuat function.
- Latihan 5: Memproses form dengan GET.
- Latihan 6: Memproses form dengan POST.
- Latihan 7: Pengolahan data sederhana.
- Mini Project: Formulir data mahasiswa.

## 5. Kesimpulan
Praktikum ini membantu memahami dasar
pemrograman PHP dan penerapannya dalam
membangun aplikasi web sederhana.
