# PRAKTIKUM 7 – PEMROGRAMAN SERVER-SIDE DENGAN PHP

## 1. Deskripsi
Praktikum ini membahas dasar-dasar pemrograman server-side menggunakan PHP. Pada praktikum ini, mahasiswa mempelajari cara menjalankan PHP menggunakan XAMPP, membuat variabel, menggunakan array, fungsi, serta mengolah data dari form menggunakan metode GET dan POST.

## 2. Tujuan Praktikum
- Memahami dasar pemrograman PHP.
- Menjalankan file PHP menggunakan web server XAMPP.
- Memahami penggunaan variabel, operator, dan percabangan.
- Menggunakan array dan perulangan `foreach`.
- Membuat dan memanggil fungsi PHP.
- Memahami pengiriman data menggunakan metode GET dan POST.
- Membuat form input dan melakukan validasi data.

## 3. Alat dan Bahan
- Laptop atau komputer.
- XAMPP.
- Visual Studio Code.
- Web browser (Google Chrome atau Microsoft Edge).

## 4. Langkah Kerja

### A. Persiapan
1. Instal aplikasi XAMPP.
2. Buka XAMPP Control Panel.
3. Aktifkan Apache.
4. Buka folder `C:\xampp\htdocs`.
5. Buat folder proyek dengan nama `Lab7Web_PHP`.
6. Buka folder tersebut menggunakan Visual Studio Code.

### B. Membuat Program PHP
Buat beberapa file PHP sesuai latihan berikut:

| No. | Nama File | Materi |
|---|---|---|
| 1 | `latihan1.php` | Menampilkan teks dan tanggal |
| 2 | `latihan2.php` | Variabel, operator, dan percabangan |
| 3 | `latihan3.php` | Array dan perulangan |
| 4 | `latihan4.php` | Function atau fungsi |
| 5 | `latihan5.php` | Form menggunakan GET |
| 6 | `latihan6.php` | Form menggunakan POST |
| 7 | `latihan7.php` | Menghitung total belanja |

### C. Mini Project
Buat file `mahasiswa.php` untuk membuat form pendataan mahasiswa.

Data yang dimasukkan:
- Nama mahasiswa.
- NIM.
- Program studi.
- Semester.
- Email.

Program akan memeriksa data yang dimasukkan sebelum menampilkan hasilnya.

## 5. Cara Menjalankan Program
1. Buka XAMPP Control Panel.
2. Klik **Start** pada Apache.
3. Buka Visual Studio Code.
4. Pastikan seluruh file PHP tersimpan di folder `C:\xampp\htdocs\Lab7Web_PHP`.
5. Buka browser.
6. Masukkan alamat berikut:

   `http://localhost/Lab7Web_PHP/latihan1.php`

7. Untuk menjalankan latihan lainnya, ganti nama file pada alamat browser.

Contoh:

- `http://localhost/Lab7Web_PHP/latihan2.php`
- `http://localhost/Lab7Web_PHP/latihan3.php`
- `http://localhost/Lab7Web_PHP/latihan4.php`
- `http://localhost/Lab7Web_PHP/latihan5.php`
- `http://localhost/Lab7Web_PHP/latihan6.php`
- `http://localhost/Lab7Web_PHP/latihan7.php`
- `http://localhost/Lab7Web_PHP/mahasiswa.php`

## 6. Hasil Praktikum
Dari kegiatan praktikum ini, mahasiswa dapat menjalankan program PHP melalui web server XAMPP, menggunakan variabel, array, perulangan, fungsi, serta mengolah data dari form dengan metode GET dan POST.

## 7. Kesimpulan
Berdasarkan praktikum yang telah dilakukan, dapat disimpulkan bahwa PHP merupakan bahasa pemrograman server-side yang dapat digunakan untuk membuat halaman web dinamis. Dengan mempelajari PHP, kita dapat mengolah data, melakukan perhitungan, membuat form, dan melakukan validasi input dari pengguna. Praktikum ini memberikan pemahaman dasar mengenai cara kerja PHP dalam pengembangan aplikasi web.
